# Operation Iron Fist

Un juego de puzzles de maquinas para ZX Spectrum 128K, de Matias Cortina.
Esto es la version para jugar con el dedo: una sola pagina, sin instalar
nada.

**Jugar: https://lesbeziers.github.io/ironfist-web/**

El motor de fisica es el mismo del juego original, verificado fotograma a
fotograma contra el codigo Z80. Los graficos salen del binario de verdad.
